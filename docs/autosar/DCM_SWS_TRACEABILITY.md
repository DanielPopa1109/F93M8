# F93 DCM selected requirement trace — 2026-10-24

This is a selected, non-exhaustive trace against the [official Classic R4.3.1 DCM SWS](https://www.autosar.org/fileadmin/standards/R4.3.1/CP/AUTOSAR_SWS_DiagnosticCommunicationManager.pdf). Both APPs use direct hooks in place of RTE/BswM. The IDs below are reviewed; every unlisted mandatory/applicable requirement remains unverified. Host tests are not a target or bus conformance result.

| Requirement / applicability | CBM and DMU source | Executed evidence | Status |
|---|---|---|---|
